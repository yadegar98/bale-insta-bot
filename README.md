# 🚀 ربات انتشار خودکار ویدیو از بله به اینستاگرام (Reels) از طریق Make.com

این پروژه یک سیستم اتوماسیون ۲۴ ساعته برای استقرار روی سرور ابری رایگان **Render.com** است که ویدیو و کپشن را از پیام‌رسان بله دریافت کرده، در یک پوشه عمومی با لینک مستقیم MP4 هاست می‌کند، و از طریق وبهوک سرویس **Make.com** و ماژول رسمی Instagram for Business به صورت Reel در پیج اینستاگرام منتشر می‌کند.

---

## 🏗 معماری کارکرد سیستم

1. **دریافت از بله:** کاربر ویدیو و کپشن را در چت ربات بله ارسال می‌کند.
2. **میزبانی ویدیو (Public MP4):** سرور ویدیو را ذخیره کرده و در روت عمومی `/videos/:filename.mp4` قرار می‌دهد.
3. **ارسال به Make.com:** سرور یک درخواست POST به وبهوک Make.com با ساختار زیر ارسال می‌کند:
   ```json
   {
     "video_url": "https://<آدرس-سرور>/videos/filename.mp4",
     "caption": "متن کپشن"
   }
   ```
4. **انتشار رسمی در اینستاگرام:** سناریوی Make.com از طریق ماژول رسمی اینستاگرام، ویدیو را دانلود کرده و به عنوان Reel منتشر می‌کند.

---

## ⚡ سیستم جلوگیری از به خواب رفتن سرور (Keep-Alive برای Render)

سرویس‌های رایگان Render در صورت عدم دریافت ترافیک به مدت ۱۵ دقیقه خاموش (Sleep) می‌شوند. این پروژه مجهز به سیستم Self-Ping داخلی است:
- یک روت بررسی سلامت در مسیر `GET /health` تعبیه شده است.
- یک تابع داخلی هر **۹ دقیقه** یک‌بار به طور خودکار این روت را صدا می‌زند (`SELF_PING_URL`).
- در نتیجه، سرور Render همیشه فعال و آنلاین می‌ماند و نیازی به هیچ سرویس خارجی مانند UptimeRobot ندارد.

## 🚀 راهنمای استقرار روی Render.com

1. فایل‌های پروژه را در یک مخزن **GitHub** قرار دهید.
2. وارد پنل **Render.com** شده و یک **New Web Service** بسازید و مخزن را انتخاب کنید.
3. مشخصات استقرار:
   - **Runtime:** `Node`
   - **Build Command:** `npm install --legacy-peer-deps && npm run build`
   - **Start Command:** `npm start`
   - **Health Check Path:** `/health`
4. متغیرهای محیطی (**Environment Variables**) در Render:

| نام متغیر | توضیحات | مقدار نمونه |
| :--- | :--- | :--- |
| `BALE_BOT_TOKEN` | توکن ربات بله از BotFather | `123456789:ABCdefGh...` |
| `MAKE_WEBHOOK_URL` | آدرس وبهوک Make.com | `https://hook.eu1.make.com/bnels556iotmn6bgg8b25ywcxtayyawp` |
| `SELF_PING_URL` | آدرس سرور رندر شما جهت پینگ ۹ دقیقه‌ای | `https://my-app.onrender.com` |
| `PUBLIC_BASE_URL` | آدرس سرور برای ساخت لینک مستقیم ویدیو | `https://my-app.onrender.com` |
| `ADMIN_CHAT_ID` | شناسه عددی ادمین بله (اختیاری) | `987654321` |
| `NODE_ENV` | حالت اجرا | `production` |

## 💻 اجرای محلی (Local)

```bash
# نصب وابستگی‌ها
npm install

# ساخت و اجرای سرور
npm run build
npm start
```
داشبورد وب بر روی پورت ۳۰۰۰ (`http://localhost:3000`) در دسترس خواهد بود.
